# 钓鱼模块 游戏背景与基础版机制

## 1. 这个模块描述什么

钓鱼是把一天划分到不同水域和不同时段的活动。相同地点在不同季节或时段会出现不同鱼类与非鱼结果，因此去哪里钓、什么时候钓会改变每竿的平均价值。

独立版本假定玩家把每天的可用时间和体力都用于钓鱼。它不模拟一次次抛竿的随机结果，而是使用大量抛竿下的平均回报，帮助使用者比较地点和时段的相对收益。

## 2. 可选地点与时段

基础版保留五个 Day 1 可到达的公共钓点：Mountain Lake、Town River、Forest River、Forest Pond、Ocean。

每天分为四个连续时段：09:00–12:00、12:00–16:00、16:00–19:00、19:00–00:00。玩家可在每个时段选择一个或多个地点安排抛竿；旅行时间不计入基础版，因此重点是比较同一时段不同地点的鱼池和平均价值。

## 3. 一次钓鱼如何计时和消耗体力

- 每次抛竿的主要游戏时间成本是等待上钩。它随当天开始时的钓鱼等级略微下降：等级 0 是 21.9 游戏分钟；每提高一级，上钩时间上限减少 0.25 现实秒。对应的平均等待时间已预先写入数据表。
- 抛竿、收线和小游戏只消耗玩家现实操作时间，基础版不把它们计入游戏时钟。
- 等级 0 时每竿消耗 8.0 点体力；每提高一级，原版基础体力消耗减少 0.1 点。每个等级的实际参数已预先写入数据表。
- 每天仍受 900 游戏分钟和 270 点体力限制。

这代表基础版关注在一个时段内能安排多少次等待上钩，而不是玩家的手速或小游戏技巧。

## 4. 鱼池与随机结果如何简化

现实游戏中的钓鱼结果受地点、季节、时段、天气、鱼竿、鱼饵、浮标位置、玩家等级和小游戏表现影响。基础版保留地点、季节与时段，固定天气为晴天，并做如下简化：

- 初始使用 Bamboo Pole。达到等级 2 并购买 Fiberglass Rod 后可使用 Standard Bait；达到等级 6 并购买 Iridium Rod 后可使用一枚吊钩。
- 所有上钩结果均视为成功捕获。
- 不考虑水深、离岸距离和具体浮标位置。
- 鱼类、Green Algae、Seaweed、各类 Jelly 和垃圾都保留为可能结果。
- 每个地点—季节—时段组合预先整理成一竿的平均金币，而不是由过程临时随机抽鱼。

因此，某个组合的平均收益并不表示每一竿都能卖出该金额，而是代表长期重复在同一条件下钓鱼时的平均回报。

## 5. 钓鱼次数经验与鱼竿资格

基础版把经验简化成一个累计次数：每一次已经结算结果的抛竿增加 1 次，无论结果是鱼、藻类／果冻、海藻还是垃圾。它不使用原版随鱼种、品质、完美捕获和宝箱变化的 XP；等级门槛则采用 Wiki 所列“累计普通沙丁鱼数量”的等价表。

等级在一天结束后更新，并在次日生效。举例说，累计 30 次结算抛竿后，次日为等级 2，可购买 1,800g 的 Fiberglass Rod；累计 254 次后，次日为等级 6，可购买 7,500g 的 Iridium Rod。购买仍需当日有足够现金，且不是自动发生。

等级除了开启购买资格，也会影响当天的鱼池筛选、基础上钩概率、等待时间和体力。因此不同时期的钓鱼不是简单地永远挑同一格最高平均收益，而是要在对应等级下比较地点与时段。

Standard Bait、Spinner 和 Dressed Spinner 已启用为实际的消耗品。Bait 每竿消耗 1 个、花费 5g，并使咬钩等待时间减半；Spinner 与 Dressed Spinner 仅可由 Iridium Rod 装备，分别使最大咬钩等待减少 5.4 和 10.7 游戏分钟。所有模型时间均统一为游戏分钟。

每枚吊钩有 20 次“捕到鱼”的耐久。藻类、果冻、海藻、垃圾和其他非鱼结果不会消耗它。由于本模块使用期望收益而非逐竿模拟，数据表把每竿预期吊钩消耗写成该条件下鱼类概率除以 20。其余吊钩只改变小游戏、品质、宝箱或信息提示，在当前固定成功率、普通品质和无宝箱收益的口径下不赋予货币效益。

## 6. 使用者应关注什么

查看独立钓鱼结果时，建议关注：

- 每个季节中，不同地点和时段的平均每竿价值；
- 每个时段可以容纳多少竿，以及是否有剩余时间；
- 每日竿数是否受体力而非时间限制；
- 鱼饵节省的等待时间是否足以抵消每竿 5g 成本；
- Spinner 或 Dressed Spinner 的一次性购买成本与预期耐久消耗是否值得；
- 鱼和非鱼结果在平均收益中的共同作用；
- 选择某个地点的原因是时段鱼池变化，而不是可出现鱼种数量更多。

联动模型中，钓鱼机制本身不变，只需与种植和采矿一起分享当天的时间、体力和现金流。
