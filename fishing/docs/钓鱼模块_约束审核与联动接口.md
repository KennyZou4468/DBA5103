## 4. 决策、派生量、输出不能混用

| 类型 | 包含什么 | 不应做什么 |
| --- | --- | --- |
| 真正选择 | x 的活动量，buy 的购竿日 | 不预先固定每天钓满或自动购竿 |
| 状态／逻辑 | N、z、u、own、B | 不将今日 N 用于今日等级；不将 u 当买装备 |
| 派生量 | 毛收入、成本、时间、体力、预期吊钩消耗 | 不人为设成新的自由决策；不重复计费 |
| 将来输出列 | 日期、等级、竿数、装备、收入、现金等 | 输出不再进入模型成为另一份库存或另一笔收入 |

主模型改用 $B_t$、$R_t^{fish}$、$C_t^{fish}$、$T_t^{fish}$、$E_t^{fish}$，与种植接口对齐。旧 PDF 的 `Cash`、`Revenue_fish`、`Cost_fish`、`Time_fish`、`Energy_fish` 分别就是这些量，含义不变。C1-C31 与 G1-G6 的分组仍可对照。

## 5. 组员联动时需要接入什么

| 接口 | 单位 | 接入方式 |
| --- | --- | --- |
| $R_t^{fish}$ | g/日 | 加入全局日末毛收入 |
| $C_t^{fish}$ | g/日 | 同时进入日初支付约束和现金平衡 |
| $T_t^{fish}$ | 游戏分钟/日 | 与 crop、mine 的时间相加不超过 900 |
| $E_t^{fish}$ | 体力/日 | 与 crop、mine 的体力相加不超过 270 |
| 钓鱼特有状态 | N、z、u、own | 留在 fishing 子模型内，跨日递推 |
| 钓鱼时段容量 | C3 | 留在钓鱼内；若别的模块增加时间窗，再建立共同的时段容量 |

联动时只建立一个 B0=500 和一条全局现金路径；删除或停用各独立模块的专属现金平衡，替换为共享 G3-G6。不要一边各自扣独立成本，一边又在全局重复扣。

当前种植与采矿的独立升级采用现金等价材料成本；采矿的累计矿石列是已折现的产出说明，不是可再花一次的库存。钓鱼无需物料输入，不在本次擅自引入金属锭、熔炼或鱼竿服务期。

## 6. 最少应做的边界检查

| 情况 | 应出现的结果 |
| --- | --- |
| 日初累计 29 / 30 次 | 分别为等级 1 / 2 |
| 日初累计 253 / 254 次 | 分别为等级 5 / 6 |
| 日初累计 530 / 531 次 | 分别为等级 7 / 8；前者没有 Dressed 活动 |
| 今日达到门槛 | 今日等级不变，次日切换 |
| 只有 Iridium、没有 Fiberglass | 允许 bait，仍要求支付每竿鱼饵 |
| 没有 Iridium | 所有含吊钩活动为 0 |
| 有资格但开盘现金不足 | 不能购入；不能借今日收入购买 |
| 同时持有两根高级鱼竿 | 不会获得第二份体力或时间；仍只启用一个日初等级 |
| 剩余时间为正 | 方案可以合法；不能强制加竿突破体力 |
| 非鱼结果 | 计一次经验，含售价，不耗吊钩耐久 |

这些是实现后需要用构造实例验证的行为；当前文档与数据检查不等于已经运行了这些 MILP 测试。

## 7. 结果文件和报告怎么整理

参照组员的“摘要 + 日程 + 约束审核”方式，未来建议导出三层结果；以下是规划字段，不是已经生成的优化 CSV。

| 文件层次 | 建议关键字段 | 用途 |
| --- | --- | --- |
| 汇总 | Scenario、Objective、Horizon、Cash_End_g、Solver_Status、Best_Bound、MIP_Gap、Solve_Seconds | 比较同口径实验，标明最优性证据 |
| 每日 | Day、Season_Day、Level_Start、Casts、Cum_Casts_End、Revenue_g、BaitCost_g、TackleCost_g、RodCost_g、Cash_End_g、Time_Min、Energy | 重建现金、成长和资源使用 |
| 活动明细 | Scenario、Objective、Horizon、Day、Time_Block、Location、Equipment_Mode、Casts | 解释何时去哪里、用了什么装备 |

汇总前先按 Scenario、Objective、Horizon 分组，不能把多个实验叠在一起相加。显示数值可四舍五入，独立复核应使用未舍入决策和系数。

报告正文可先使用以下问题定义，之后再接入真实结果：

> 钓鱼模块将第一年 112 天的地点、时段、抛竿数量和装备购买统一建模为多期混合整数线性规划。每竿收入、等待和消耗由等级及环境条件下的预计算期望系数确定；每日活动同时受时段容量、时间、体力及开盘现金限制。累计已结算抛竿决定次日等级，装备投资则开启新的活动模式。模型在保留跨日成长和投资取舍的同时，以确定性系数代替逐竿随机模拟，目标是最大化年末现金。

后续结果应分别回答：资源瓶颈是什么、装备为何买或不买、地点为何随季节／时段变化、长期规划比基准改善多少。尚未求解时不写“始终选某地”“一有钱立即升级”等策略结论。
